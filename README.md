# نزال النيون — Neon Showdown

لعبة قتال أنمي في شارع نيون مطر، بشخصيتين أصليتين (كاي ورين).

- ضد الكمبيوتر (3 مستويات صعوبة)
- أونلاين بكود غرفة أو رابط دعوة (WebRTC عبر PeerJS)
- تتنزل على التليفون كتطبيق (PWA) من زر "نزّل اللعبة على التليفون"

## التشغيل
افتح `index.html` من أي استضافة HTTPS (مثل GitHub Pages). التنزيل على التليفون والأونلاين بيحتاجوا رابط HTTPS مش ملف محلي.

## التحكم
A/D حركة · W أو Space نط · S دفاع · J لكمة · K ركلة · L مسكة ورمي · I ضربة خاصة · Esc إيقاف
